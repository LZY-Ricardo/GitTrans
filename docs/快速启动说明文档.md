# GitTrans 快速启动说明文档

## 1. 当前项目包含什么

当前已经实现：

- GitHub App 登录入口与回调
- 仓库导入
- 仓库配置读写
- 文件树读取
- 全量/增量任务创建
- Worker 轮询执行
- OpenRouter Markdown 翻译
- README 导航插入
- GitHub 分支提交与 PR 更新
- Webhook 去重与增量任务入队

## 2. 最快启动方式

### 2.1 安装依赖

```bash
npm install
```

### 2.2 准备环境变量

参考 [\.env.example](F:/myProjects/GitTrans/.env.example) 创建 `.env`。

最少先保证：

```env
DATABASE_URL=mysql://gittrans:gittrans@127.0.0.1:3306/gittrans
APP_BASE_URL=http://localhost:3000
APP_ENCRYPTION_KEY=your-secret
SESSION_SECRET=your-session-secret
```

### 2.3 启动 MySQL

如果你本机没有 MySQL，可以用 Docker：

```bash
docker compose -f docker/docker-compose.yml up -d mysql
```

注意：

- 我在当前机器上未能直接启动 Docker 守护进程，所以这里只能提供命令，未完成实际容器启动验证

### 2.4 初始化数据库

```bash
npm run prisma:deploy
```

### 2.5 启动 Web 服务

开发模式：

```bash
npm run dev
```

生产构建：

```bash
npm run build
npm run start
```

### 2.6 启动 Worker

单独开一个终端执行：

```bash
npm run worker
```

## 4. 推荐的本地启动顺序

1. 配好 `.env`
2. 起 MySQL
3. 执行 `npm run prisma:deploy`
4. 执行 `npm run dev`
5. 新开终端执行 `npm run worker`
6. 访问 `http://localhost:3000/api/health`
7. 再继续做 GitHub App 登录和仓库导入测试

## 5. 容器启动方式

如果你已经配置好 `.env`，也可以直接启动整套服务：

```bash
docker compose -f docker/docker-compose.yml up --build
```

服务说明：

- `mysql`: MySQL 8.4
- `web`: Next.js API 服务
- `worker`: 任务轮询与执行进程
