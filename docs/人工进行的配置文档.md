# GitTrans 人工进行的配置文档

## 1. 需要你手工准备的外部资源

### 1.1 GitHub App

你需要在 GitHub 创建一个 GitHub App，并填写以下配置：

| 配置项 | 建议值 |
|---|---|
| Homepage URL | `http://localhost:3000` 或你的正式域名 |
| Callback URL | `http://localhost:3000/api/auth/github/callback` |
| Setup URL | `http://localhost:3000/dashboard` |
| Webhook URL | `http://localhost:3000/api/github/webhooks` |
| Webhook Secret | 自己生成一串高强度随机字符串 |

推荐权限：

- `Metadata: Read`
- `Contents: Read & Write`
- `Pull requests: Read & Write`

推荐事件订阅：

- `Installation`
- `Installation repositories`
- `Push`

创建完成后，记录这些值：

- `GITHUB_APP_ID`
- `GITHUB_APP_SLUG`
- `GITHUB_APP_CLIENT_ID`
- `GITHUB_APP_CLIENT_SECRET`
- `GITHUB_APP_PRIVATE_KEY`
- `GITHUB_WEBHOOK_SECRET`

### 1.2 OpenRouter

你需要到 OpenRouter 创建 API Key，然后记录：

- `OPENROUTER_PLATFORM_API_KEY`

当前实现中，前端不会直接调用 OpenRouter，所有请求都由后端统一发起。

### 1.3 MySQL

项目当前固定使用 MySQL。

你可以任选一种方式：

- 本机已有 MySQL 8+
- 使用 Docker 启动 MySQL

默认数据库连接配置是：

```env
DATABASE_URL=mysql://gittrans:gittrans@127.0.0.1:3306/gittrans
```

## 2. 需要你手工填写的环境变量

参考 [\.env.example](F:/myProjects/GitTrans/.env.example) 创建本地 `.env`。

关键变量说明：

| 变量 | 说明 |
|---|---|
| `APP_BASE_URL` | Web 服务访问地址 |
| `DATABASE_URL` | MySQL 连接串 |
| `APP_ENCRYPTION_KEY` | 用于加密 GitHub/OpenRouter 敏感字段 |
| `SESSION_SECRET` | 用于会话 token 哈希 |
| `GITHUB_APP_ID` | GitHub App ID |
| `GITHUB_APP_SLUG` | GitHub App slug |
| `GITHUB_APP_CLIENT_ID` | GitHub App Client ID |
| `GITHUB_APP_CLIENT_SECRET` | GitHub App Client Secret |
| `GITHUB_APP_PRIVATE_KEY` | GitHub App 私钥内容 |
| `GITHUB_WEBHOOK_SECRET` | GitHub Webhook HMAC Secret |
| `OPENROUTER_PLATFORM_API_KEY` | OpenRouter 平台托管 Key |

注意：

- `GITHUB_APP_PRIVATE_KEY` 在 `.env` 中需要把换行转成 `\n`
- `APP_ENCRYPTION_KEY` 和 `SESSION_SECRET` 不要继续使用示例值

## 3. 需要你手工执行的数据库初始化

项目已经包含初始化迁移：

- [prisma/migrations/20260315100000_init/migration.sql](F:/myProjects/GitTrans/prisma/migrations/20260315100000_init/migration.sql)

数据库初始化步骤：

1. 确保 MySQL 已启动
2. 确保 `DATABASE_URL` 指向正确的库
3. 执行：

```bash
npm run prisma:deploy
```

如果你本地是第一次启动，也可以使用：

```bash
npm run prisma:migrate -- --name init
```

## 4. 需要你手工完成的 GitHub 侧动作

### 4.1 安装 GitHub App

把 GitHub App 安装到你要翻译的目标仓库所在账号或组织下。

### 4.2 授权测试账号登录

服务启动后，访问：

```text
http://localhost:3000/api/auth/github/start
```

完成 GitHub 登录授权。

### 4.3 Webhook 联通

如果你是本地开发环境，GitHub Webhook 无法直接访问本地地址，你需要自己提供一个公网入口，例如：

- Nginx 反向代理
- Cloudflare Tunnel
- ngrok

然后把 GitHub App 的 Webhook URL 改成可公网访问的地址。
